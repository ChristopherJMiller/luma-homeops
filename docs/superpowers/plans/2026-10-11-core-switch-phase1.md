# Core switch as code — phase 1 (remote) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `swctl` (status / import / plan / apply / disarm / backup / save) manages the TEG-30284's VLANs and ports from `switch/teg-30284.yaml`, with a router-side dead-man; the router's eth3 is ready for the switch's dedicated management link and VLAN 99 waits on port 2.

**Architecture:** Python stdlib + PyYAML tool in `tools/swctl`, laid out like `tools/hactl`. Every switch operation runs **on the router** over one SSH session per call (`net-snmp` there; credentials in a temp `snmp.conf`, never argv). Pure logic (bitmaps, state model, desired file, diff, inventory) is unit-tested; `apply` is tested end-to-end against a fake switch that interprets the same SNMP writes.

**Tech Stack:** Python 3.12+ (dev shell's `hactlPython`: pyyaml + pytest), net-snmp + python3 + systemd-run on VyOS 1.5, Ansible (`router/ansible`).

**Spec:** `docs/superpowers/specs/2026-10-11-core-switch-as-code-design.md`

## Global Constraints

- Ports are exactly 1–28; PortList bitmaps are 8 bytes; port N = bit `0x80 >> (N-1)%8` of byte `(N-1)//8`.
- VLAN create = `dot1qVlanStaticRowStatus` createAndGo (4) **in its own PDU**; destroy = 6; names ≤ 32 chars.
- Every port: exactly one untagged VLAN, PVID equal to it. VLAN 1 never deleted.
- `management: {port, vlan, address}` is never changed by `swctl`; the live switch must match it before any write.
- Credentials only in `switch/credentials.secret.yaml` (git-crypt); never on a command line, in output, or in a commit message.
- Never send CLI `reset` or `reboot`; every CLI session ends with `logout`.
- Switch writes that touch VLAN 1's bitmaps wait until no DVR recording is in progress (`/media/subscriptions/scheduled` has no `inprogress`).
- Router changes only through `router/ansible` with the commit-confirm parachute (vyos-deploy skill).

## Review Focus

1. **A live port untagged in two VLANs** (the switch allows it) — `import` must refuse naming the port; `plan` must converge it to one. Tests: Task 2 `test_import_refuses_double_untagged` (in Task 4's commands tests), Task 3 `test_diff_fixes_double_untagged`.
2. **A desired file that would move the management port or delete its VLAN, or a live switch whose management port was changed by hand** — refused before any write. Tests: Task 2 `test_management_port_must_be_untagged_in_management_vlan`, Task 3 `test_check_management_refuses_hand_changed_live`.
3. **A dead-man left armed by a crashed run** — `apply` refuses until `swctl disarm`. Test: Task 5 `test_apply_refuses_when_deadman_armed`.
4. **A write failing half-way** — the in-session revert converges from the *actual* live state back to the snapshot. Test: Task 5 `test_apply_reverts_partial_failure`.
5. **The operator's session dying after the writes** — the router reverts on its own. Test: Task 5 `test_simulated_session_loss_leaves_deadman_armed` + the live rehearsal (Task 5 Step 7).

```python
"""Q-BRIDGE PortList bitmaps: port N is bit 0x80 >> (N-1)%8 of byte (N-1)//8."""


def decode(hexstr: str) -> set[int]:
    data = bytes.fromhex(hexstr.replace(" ", ""))
    return {i * 8 + b + 1 for i, byte in enumerate(data) for b in range(8) if byte & (0x80 >> b)}


def encode(ports: set[int], length: int) -> str:
    data = bytearray(length)
    for p in ports:
        if not 1 <= p <= length * 8:
            raise ValueError(f"port {p} does not fit a {length}-byte PortList")
        data[(p - 1) // 8] |= 0x80 >> ((p - 1) % 8)
    return " ".join(f"{b:02X}" for b in data)
```

`tools/swctl/src/swctl/model.py`:
```python
"""Switch state (VLANs, per-port membership) as the Q-BRIDGE MIB stores it."""
from __future__ import annotations

from dataclasses import dataclass

from swctl import bitmap

PORTS = 28                                   # TEG-30284: 24x1G + 4x10G SFP+ (25-28)
QB = "1.3.6.1.2.1.17.7.1.4"                  # Q-BRIDGE-MIB dot1qVlan
VLAN_NAME = f"{QB}.3.1.1"
VLAN_EGRESS = f"{QB}.3.1.2"                  # every member, tagged or untagged
VLAN_UNTAGGED = f"{QB}.3.1.4"
VLAN_STATUS = f"{QB}.3.1.5"                  # RowStatus: 4 createAndGo, 6 destroy
PVID = f"{QB}.5.1.1"
STATE_OIDS = [f"{QB}.3.1", PVID]


@dataclass
class Port:
    untagged: set[int]                       # the switch allows several; a desired port has one
    tagged: set[int]
    pvid: int


@dataclass
class SwitchState:
    vlans: dict[int, str]                    # vid -> name
    ports: dict[int, Port]                   # 1..PORTS
    bitmap_len: int = 8                      # bytes in this switch's PortLists

    def members(self, vid: int) -> tuple[set[int], set[int]]:
        """(egress, untagged) port sets of a VLAN, the way the switch stores them."""
        untagged = {p for p, port in self.ports.items() if vid in port.untagged}
        tagged = {p for p, port in self.ports.items() if vid in port.tagged}
        return untagged | tagged, untagged


def parse_walk(text: str) -> dict[str, str]:
    """`snmpbulkwalk -On -Oq -Ox -Oe` output -> {oid: value}. Octet strings stay
    hex; net-snmp's continuation lines (hex wrapped at 16 bytes) are joined."""
    values: dict[str, str] = {}
    last = None
    for raw in text.splitlines():
        line = raw.strip()
        if line.startswith("."):
            oid, _, value = line.partition(" ")
            last = oid[1:]
            values[last] = value
        elif line and last is not None:
            values[last] += " " + line
    return {oid: " ".join(v.replace('"', " ").split()) for oid, v in values.items()}


def rows(values: dict[str, str], prefix: str) -> dict[int, str]:
    """The single-integer-indexed rows of one column."""
    p = prefix + "."
    return {int(k[len(p):]): v for k, v in values.items() if k.startswith(p) and k[len(p):].isdigit()}


def state_from_walk(values: dict[str, str], nports: int = PORTS) -> SwitchState:
    egress_hex = rows(values, VLAN_EGRESS)
    egress = {vid: bitmap.decode(h) for vid, h in egress_hex.items()}
    untagged = {vid: bitmap.decode(h) for vid, h in rows(values, VLAN_UNTAGGED).items()}
    names = rows(values, VLAN_NAME)
    pvids = {p: int(v) for p, v in rows(values, PVID).items()}
    vids = set(rows(values, VLAN_STATUS)) | set(egress)
    vlans = {vid: bytes.fromhex(names.get(vid, "").replace(" ", "")).decode(errors="replace") for vid in vids}
    ports = {}
    for p in range(1, nports + 1):
        u = {vid for vid, members in untagged.items() if p in members}
        t = {vid for vid, members in egress.items() if p in members} - u
        ports[p] = Port(untagged=u, tagged=t, pvid=pvids.get(p, 0))
    lengths = {len(h.split()) for h in egress_hex.values()}
    return SwitchState(vlans=vlans, ports=ports, bitmap_len=max(lengths, default=8))
```

`tools/swctl/src/swctl/desired.py`:
```python
"""switch/teg-30284.yaml <-> desired switch state."""
from __future__ import annotations

import ipaddress
import json
from dataclasses import dataclass, field
from pathlib import Path

import yaml

from swctl.errors import SwctlError
from swctl.model import PORTS, Port, SwitchState

HEADER = """\
# TRENDnet TEG-30284 core switch: desired VLAN/port state (switch/README.md).
# `swctl plan` diffs it against the switch; `swctl apply` converges it. Every VLAN
# and every port 1-28 is listed, and a port is in exactly the VLANs named here.
# `management` is the router's path to the switch: swctl never changes it.
# `canaries` must still answer ARP after every apply."""


@dataclass
class Desired:
    management_port: int
    management_vlan: int
    address: str
    state: SwitchState
    desc: dict[int, str]
    canaries: list[str] = field(default_factory=list)


def load(path: Path) -> Desired:
    try:
        doc = yaml.safe_load(path.read_text())
    except (OSError, yaml.YAMLError) as e:
        raise SwctlError(f"{path}: {e}")
    return from_doc(doc, str(path))


def from_doc(doc, where: str = "desired state") -> Desired:
    if not isinstance(doc, dict):
        raise SwctlError(f"{where}: not a mapping")
    problems: list[str] = []
    vlans: dict[int, str] = {}
    for vid, name in (doc.get("vlans") or {}).items():
        if not isinstance(vid, int) or not 1 <= vid <= 4094:
            problems.append(f"VLAN id {vid!r} is not 1-4094")
            continue
        name = "" if name is None else str(name)
        if len(name) > 32:
            problems.append(f"VLAN {vid} name longer than 32 characters")
        vlans[vid] = name
    if 1 not in vlans:
        problems.append("VLAN 1 must exist")

    ports_doc = doc.get("ports") or {}
    want = set(range(1, PORTS + 1))
    if set(ports_doc) != want:
        missing = sorted(want - set(ports_doc))
        unknown = sorted(map(str, set(ports_doc) - want))
        problems.append(f"ports must be exactly 1-{PORTS} (missing {missing}, unknown {unknown})")
    ports: dict[int, Port] = {}
    desc: dict[int, str] = {}
    for p, spec in ports_doc.items():
        if not isinstance(p, int) or not isinstance(spec, dict):
            continue
        u, tagged = spec.get("untagged"), spec.get("tagged") or []
        if not isinstance(u, int) or u not in vlans:
            problems.append(f"port {p}: untagged VLAN {u!r} is not in vlans")
        if not isinstance(tagged, list) or any(not isinstance(t, int) or t not in vlans for t in tagged):
            problems.append(f"port {p}: tagged {tagged!r} names a VLAN not in vlans")
            tagged = []
        if u in tagged:
            problems.append(f"port {p}: VLAN {u} is both untagged and tagged")
        ports[p] = Port(untagged={u}, tagged=set(tagged) - {u}, pvid=u if isinstance(u, int) else 0)
        desc[p] = str(spec.get("desc") or "")

    mgmt = doc.get("management") or {}
    mp, mv, address = mgmt.get("port"), mgmt.get("vlan"), mgmt.get("address")
    if mp not in ports:
        problems.append(f"management.port {mp!r} is not a port")
    elif ports[mp].untagged != {mv}:
        problems.append(f"management port {mp} must be untagged in the management VLAN {mv}")
    if not isinstance(address, str) or not address:
        problems.append("management.address is missing")
    if isinstance(mv, int) and mv != 1:
        others = sorted(p for p, port in ports.items() if p != mp and mv in port.untagged | port.tagged)
        if others:
            problems.append(f"management VLAN {mv} must be on port {mp} only, also on {others}")

    canaries = [str(c) for c in doc.get("canaries") or []]
    for c in canaries:
        try:
            ipaddress.IPv4Address(c)
        except ValueError:
            problems.append(f"canary {c!r} is not an IPv4 address")

    if problems:
        raise SwctlError(f"{where}:\n  " + "\n  ".join(problems))
    return Desired(mp, mv, address, SwitchState(vlans=vlans, ports=ports), desc, canaries)


def dump(d: Desired) -> str:
    lines = [HEADER,
             f"management: {{port: {d.management_port}, vlan: {d.management_vlan}, address: {d.address}}}",
             f"canaries: [{', '.join(d.canaries)}]",
             "vlans:"]
    lines += [f"  {vid}: {json.dumps(name)}" for vid, name in sorted(d.state.vlans.items())]
    lines.append("ports:")
```

```python
"""A switch that stores what the TEG-30284 stores (per-VLAN egress/untagged
bitmaps, per-port PVID) and interprets swctl's SNMP writes the same way."""
from __future__ import annotations

import copy

from swctl import bitmap
from swctl.model import PORTS, PVID, VLAN_EGRESS, VLAN_NAME, VLAN_STATUS, VLAN_UNTAGGED, SwitchState


class FakeSwitch:
    def __init__(self, state: SwitchState):
        self.vlans = {vid: [name, *state.members(vid)] for vid, name in state.vlans.items()}  # vid -> [name, egress, untagged]
        self.pvid = {p: port.pvid for p, port in state.ports.items()}

    def write(self, op) -> None:
        col, idx = op.oid.rsplit(".", 1)
        idx = int(idx)
        if col == VLAN_STATUS and op.value == "4":
            if idx in self.vlans:
                raise RuntimeError(f"VLAN {idx} exists")
            self.vlans[idx] = ["", set(), set()]
        elif col == VLAN_STATUS and op.value == "6":
            if idx not in self.vlans:
                raise RuntimeError(f"no VLAN {idx}")
            del self.vlans[idx]
        elif idx not in self.vlans and col != PVID:
            raise RuntimeError(f"no VLAN {idx}")
        elif col == VLAN_NAME:
            self.vlans[idx][0] = op.value
        elif col == VLAN_EGRESS:
            self.vlans[idx][1] = bitmap.decode(op.value)
            self.vlans[idx][2] &= self.vlans[idx][1]
        elif col == VLAN_UNTAGGED:
            self.vlans[idx][2] = bitmap.decode(op.value)
            self.vlans[idx][1] |= self.vlans[idx][2]
        elif col == PVID:
            self.pvid[idx] = int(op.value)
        else:
            raise RuntimeError(f"unexpected write {op}")

    def walk_text(self) -> str:
        out = []
        for vid, (name, egress, untagged) in sorted(self.vlans.items()):
            hexname = " ".join(f"{b:02X}" for b in name.encode())
            out += [f'.{VLAN_NAME}.{vid} "{hexname}"', f'.{VLAN_EGRESS}.{vid} "{bitmap.encode(egress, 8)}"',
                    f'.{VLAN_UNTAGGED}.{vid} "{bitmap.encode(untagged, 8)}"', f".{VLAN_STATUS}.{vid} 1"]
        out += [f".{PVID}.{p} {v}" for p, v in sorted(self.pvid.items())]
        return "\n".join(out) + "\n"

    def state(self) -> SwitchState:
        from swctl.model import parse_walk, state_from_walk
        return state_from_walk(parse_walk(self.walk_text()))


def clone(state: SwitchState) -> SwitchState:
    return copy.deepcopy(state)


def flat(vlans=None, overrides=None) -> SwitchState:
    """All 28 ports untagged in VLAN 1, then per-port overrides {p: (untagged set, tagged set, pvid)}."""
    from swctl.model import Port
    ports = {p: Port({1}, set(), 1) for p in range(1, PORTS + 1)}
    for p, (u, t, pv) in (overrides or {}).items():
        ports[p] = Port(set(u), set(t), pv)
    return SwitchState(vlans=vlans or {1: "DefaultVLAN"}, ports=ports)
```

```python
"""Desired vs live -> ordered SNMP writes; the management-path guard."""
from __future__ import annotations

from dataclasses import dataclass

from swctl import bitmap
from swctl.errors import SwctlError
from swctl.model import PVID, VLAN_EGRESS, VLAN_NAME, VLAN_STATUS, VLAN_UNTAGGED, SwitchState

CREATE_AND_GO, DESTROY = 4, 6


@dataclass(frozen=True)
class Op:
    oid: str
    type: str                                # snmpset type letter: i, u, s, x
    value: str
    why: str


def _ports(ps: set[int]) -> str:
    return ",".join(map(str, sorted(ps))) or "none"


def diff(current: SwitchState, target: SwitchState) -> list[Op]:
    """The writes that turn `current` into `target`, ordered so no port is ever
    without an untagged VLAN: create VLANs, add members, set PVIDs, remove
    members, delete VLANs. Every write is absolute, so a diff from a half-applied
    state converges too."""
    n = current.bitmap_len
    ops: list[Op] = []
    for vid in sorted(set(target.vlans) - set(current.vlans)):
        ops.append(Op(f"{VLAN_STATUS}.{vid}", "i", str(CREATE_AND_GO), f"create VLAN {vid}"))
    for vid, name in sorted(target.vlans.items()):
        if current.vlans.get(vid, "") != name:
            ops.append(Op(f"{VLAN_NAME}.{vid}", "s", name, f"VLAN {vid}: name {name!r}"))
    removals: list[Op] = []
    for vid in sorted(target.vlans):
        cur_e, cur_u = current.members(vid) if vid in current.vlans else (set(), set())
        tgt_e, tgt_u = target.members(vid)
        mid_e, mid_u = cur_e | tgt_e, cur_u | tgt_u
        if mid_e != cur_e:
            ops.append(Op(f"{VLAN_EGRESS}.{vid}", "x", bitmap.encode(mid_e, n), f"VLAN {vid}: add ports {_ports(mid_e - cur_e)}"))
        if mid_u != cur_u:
            ops.append(Op(f"{VLAN_UNTAGGED}.{vid}", "x", bitmap.encode(mid_u, n), f"VLAN {vid}: ports {_ports(mid_u - cur_u)} untagged"))
        if tgt_u != mid_u:
            removals.append(Op(f"{VLAN_UNTAGGED}.{vid}", "x", bitmap.encode(tgt_u, n), f"VLAN {vid}: ports {_ports(mid_u - tgt_u)} no longer untagged"))
        if tgt_e != mid_e:
            removals.append(Op(f"{VLAN_EGRESS}.{vid}", "x", bitmap.encode(tgt_e, n), f"VLAN {vid}: remove ports {_ports(mid_e - tgt_e)}"))
    for p, port in sorted(target.ports.items()):
        if current.ports[p].pvid != port.pvid:
            ops.append(Op(f"{PVID}.{p}", "u", str(port.pvid), f"port {p}: PVID {current.ports[p].pvid} -> {port.pvid}"))
    ops += removals
    for vid in sorted(set(current.vlans) - set(target.vlans)):
        ops.append(Op(f"{VLAN_STATUS}.{vid}", "i", str(DESTROY), f"delete VLAN {vid}"))
    return ops


def check_management(d, live: SwitchState) -> None:
    """The live management path must be exactly what the file declares; the
    file itself is validated to keep it (desired.from_doc)."""
    mp, mv = d.management_port, d.management_vlan
    port = live.ports.get(mp)
    if mv in live.vlans and port is not None and port.untagged == {mv} and port.pvid == mv:
        return
    seen = f"untagged {sorted(port.untagged)}, PVID {port.pvid}" if port else "no such port"
    raise SwctlError(
        f"the live switch does not have management port {mp} untagged in VLAN {mv} with PVID {mv} ({seen}). "
        "The management path changes only by hand (switch/README.md); refusing to write.", exit_code=3)


def changed_ports(current: SwitchState, target: SwitchState) -> dict[int, bool]:
    """port -> True when its untagged VLAN changes (its devices are expected to move)."""
    out = {}
    for p, t in sorted(target.ports.items()):
        c = current.ports[p]
        if (c.untagged, c.tagged, c.pvid) != (t.untagged, t.tagged, t.pvid):
            out[p] = c.untagged != t.untagged
    return out
```

```python
class FakeRouter:
    """Router stand-in: SNMP reads/writes go to a FakeSwitch."""

    def __init__(self, state, fdb_text="", neigh="", responding=(), fail_at=None, lose_after_writes=()):
        self.switch = FakeSwitch(state)
        self.fdb_text, self.neigh = fdb_text, neigh
        self.responding, self.lose_after_writes = set(responding), set(lose_after_writes)
        self.fail_at, self.armed, self.revert_ops, self.writes = fail_at, False, None, 0

        return self.fdb_text if oids == [FDB_PORT] else self.switch.walk_text()

    def walk(self, oids):
        from swctl.model import parse_walk
        return parse_walk(self.walk_text(oids))

    def run(self, script):
        return self.neigh if "neigh" in script else ""

        out = []
        for i, op in enumerate(ops):

            self.responding -= self.lose_after_writes
        return out

        return self.armed
```

```python
switch's management network: one `ssh … bash -s` per call, the script on stdin."""

import subprocess

import yaml

from swctl.errors import SwctlError
from swctl.model import parse_walk

ROUTER = "chris@192.168.0.1"
DEADMAN = "swctl-deadman"

def load_snmp_conf(path: Path) -> str:
    try:
        conf = yaml.safe_load(path.read_bytes())["snmp_conf"]
    except (OSError, KeyError, TypeError, UnicodeDecodeError, yaml.YAMLError) as e:
        raise SwctlError(f"{path}: cannot read snmp_conf ({e.__class__.__name__}) — is git-crypt unlocked?")
    return str(conf)


def snmp_prelude(snmp_conf: str) -> str:
    """Shell that points net-snmp at a private config holding the credentials,
    so they never reach a command line (ps) or a log."""
    return ("SWCTL_SNMP=$(mktemp -d); trap 'rm -rf \"$SWCTL_SNMP\"' EXIT\n"
            "cat > \"$SWCTL_SNMP/snmp.conf\" <<'SWCTL_CONF'\n"
            f"{snmp_conf.rstrip()}\n"
            "SWCTL_CONF\n"
            'export SNMPCONFPATH="$SWCTL_SNMP"\n')


def set_script(ops: list[Op], address: str, stop_on_error: bool) -> str:
    """One snmpset per op, reporting `OK i` or `FAIL i <error>` per line."""
    lines = []
    for i, op in enumerate(ops):
        cmd = f"snmpset -On -t3 -r1 {address} {op.oid} {op.type} {shlex.quote(op.value)}"
        on_fail = f'echo "FAIL {i} $(echo $out)"' + ("; exit 1" if stop_on_error else "")
        lines.append(f'if out=$({cmd} 2>&1); then echo "OK {i}"; else {on_fail}; fi')
    return "\n".join(lines) + "\n"


@dataclass
class Router:
    address: str                             # the switch, as the router reaches it
    snmp_conf: str
    host: str = ROUTER

    def sh(self, script: str) -> subprocess.CompletedProcess:
        try:
            return subprocess.run(["ssh", "-o", "BatchMode=yes", "-o", "ConnectTimeout=10", self.host, "bash", "-s"],
                                  input=script, capture_output=True, text=True, timeout=300)
        except subprocess.TimeoutExpired:
            raise SwctlError(f"ssh {self.host}: timed out")

    def run(self, script: str) -> str:
        r = self.sh(script)
        if r.returncode != 0:
            raise SwctlError(f"on {self.host}: {(r.stderr or r.stdout).strip()[-400:]}")
        return r.stdout

    def walk_text(self, oids: list[str]) -> str:
        body = "".join(f"snmpbulkwalk -On -Oq -Ox -Oe -t3 -r1 {self.address} {o}\n" for o in oids)
        return self.run("set -e\n" + snmp_prelude(self.snmp_conf) + body)

    def walk(self, oids: list[str]) -> dict[str, str]:
        return parse_walk(self.walk_text(oids))

    def apply(self, ops: list[Op], stop_on_error: bool = True) -> list[str]:
        r = self.sh(snmp_prelude(self.snmp_conf) + set_script(ops, self.address, stop_on_error))
        return [l for l in r.stdout.splitlines() if l.startswith(("OK ", "FAIL "))]

    def deadman_armed(self) -> bool:
        return self.sh(f"systemctl is-active --quiet {DEADMAN}.timer").returncode == 0

    def arm_deadman(self, revert_ops: list[Op], minutes: int) -> None:
        revert = ("#!/bin/bash\n# swctl dead-man: put the switch back as it was before an apply.\n"
                  f'logger -t swctl "dead-man firing: {len(revert_ops)} reverting writes"\n'
                  + snmp_prelude(self.snmp_conf)
                  + set_script(revert_ops, self.address, stop_on_error=False)
                  + f"rm -f {REVERT_FILE}\n")
        self.run("set -e\n"
                 f"if systemctl is-active --quiet {DEADMAN}.timer; then echo 'dead-man already armed' >&2; exit 3; fi\n"
                 f"sudo systemctl reset-failed {DEADMAN}.service {DEADMAN}.timer 2>/dev/null || true\n"
                 f"umask 077\ncat > {REVERT_FILE} <<'SWCTL_REVERT'\n{revert}SWCTL_REVERT\n"
                 f"sudo systemd-run --quiet --unit={DEADMAN} --on-active={int(minutes)}min /bin/bash {REVERT_FILE}\n"
                 f"systemctl is-active --quiet {DEADMAN}.timer\n")

    def disarm_deadman(self) -> None:
        self.run(f"sudo systemctl stop {DEADMAN}.timer 2>/dev/null || true\nrm -f {REVERT_FILE}\n"
                 f"! systemctl is-active --quiet {DEADMAN}.timer\n")

    def responders(self, ips: list[str]) -> set[str]:
        """Which hosts answer ARP from the router (L2 reachability; ping can be filtered)."""
        body = ""
        for ip in ips:
            ip = str(ipaddress.IPv4Address(ip))
            body += (f'( dev=$(ip -o route get {ip} | sed -n "s/.* dev \\([^ ]*\\).*/\\1/p"); '
                     f'sudo arping -q -c 2 -w 3 -I "$dev" {ip} && echo {ip} ) &\n')
        return set(self.sh(body + "wait\n").stdout.split()) if body else set()
```

```python
neighbour table and DHCP leases."""
from __future__ import annotations

from dataclasses import dataclass

FDB_PORT = "1.3.6.1.2.1.17.7.1.2.2.1.2"      # dot1qTpFdbPort, index fdbId.mac[6]
IF_OPER = "1.3.6.1.2.1.2.2.1.8"              # 1 up, 2 down
IF_SPEED = "1.3.6.1.2.1.31.1.1.1.15"         # ifHighSpeed, Mb/s
NEIGH_CMD = "ip -4 neigh show"
LEASES_CMD = "/opt/vyatta/bin/vyatta-op-cmd-wrapper show dhcp server leases"


@dataclass(frozen=True)
class Device:
    mac: str
    ip: str = ""
    name: str = ""

    def label(self) -> str:
        where = f".{self.ip.rsplit('.', 1)[1]}" if self.ip.startswith("192.168.0.") else self.ip
        return " ".join(x for x in (self.name or self.mac, where) if x)


def fdb(values: dict[str, str]) -> dict[int, list[str]]:
    out: dict[int, list[str]] = {}
    prefix = FDB_PORT + "."
    for oid, port in values.items():
        parts = oid[len(prefix):].split(".") if oid.startswith(prefix) else []
        if len(parts) == 7 and port.isdigit():
            out.setdefault(int(port), []).append(":".join(f"{int(x):02x}" for x in parts[1:]))
    return out


def neighbours(text: str) -> dict[str, str]:
    out = {}
    for line in text.splitlines():
        f = line.split()
        if "lladdr" in f and f.index("lladdr") + 1 < len(f):
            out[f[f.index("lladdr") + 1].lower()] = f[0]
    return out


def lease_names(text: str) -> dict[str, str]:
    """VyOS `show dhcp server leases` -> ip -> hostname, by header column position."""
    lines = text.splitlines()
    header = next((l for l in lines if l.startswith("IP Address")), "")
    if "Hostname" not in header:
        return {}
    start, end = header.index("Hostname"), (header.index("Origin") if "Origin" in header else None)
    out = {}
    for line in lines:
        ip = line.split()[0] if line.split() else ""
        name = line[start:end].strip() if len(line) > start else ""
        if ip[:1].isdigit() and name:
            out[ip] = name
    return out


def devices_by_port(fdb_ports: dict[int, list[str]], neigh: dict[str, str], names: dict[str, str]) -> dict[int, list[Device]]:
    out = {}
    for port, macs in fdb_ports.items():
        out[port] = [Device(mac, neigh.get(mac, ""), names.get(neigh.get(mac, ""), "")) for mac in sorted(macs)]
    return out
```

```python
    r = make_router(old.address if old else DEFAULT_ADDRESS)
    live = read_state(r)
    bad = {p: sorted(port.untagged) for p, port in live.ports.items() if len(port.untagged) != 1}
    if bad:
        raise SwctlError("ports not untagged in exactly one VLAN — fix on the switch first: "
                         + "; ".join(f"port {p} {v}" for p, v in sorted(bad.items())))
    for p, port in sorted(live.ports.items()):
        if {port.pvid} != port.untagged:
            print(f"note: port {p} PVID {port.pvid} differs from its untagged VLAN {sorted(port.untagged)}; "
                  "the file uses the untagged VLAN, so `swctl plan` will fix the PVID")

        desc = old.desc
    else:
        desc = {}
        for p, ds in _devices(r).items():

        return 0
```

```python
def canary_ips(r, d: Desired, changed: dict[int, bool]) -> list[str]:
    """The file's canaries plus every device on a changed port that should not move."""
    ips = set(d.canaries)
    staying = [p for p, moves in changed.items() if not moves]
    if staying:
        ports, neigh = fdb(r.walk([FDB_PORT])), neighbours(r.run(NEIGH_CMD))
        ips |= {neigh[mac] for p in staying for mac in ports.get(p, []) if mac in neigh}
    return sorted(ips, key=ipaddress.IPv4Address)


def revert_to(r, snapshot: SwitchState) -> None:
    """Converge back to `snapshot` from wherever the switch really is."""
    for _ in range(2):
        ops = diff(read_state(r), snapshot)
        if not ops:
            print("reverted: the switch matches its state before this apply")
            return
        r.apply(ops, stop_on_error=False)
    raise SwctlError("REVERT INCOMPLETE: the switch differs from its pre-apply state. The dead-man is still "
                     "armed and will retry; check `swctl plan`.", exit_code=4)


def cmd_apply(args) -> int:
    d = desired_mod.load(args.file)
    r = make_router(d.address)
    if r.deadman_armed():
        raise SwctlError("a dead-man is already armed: an earlier apply did not finish. "
                         "Check `swctl status`/`plan`, then `swctl disarm`.", exit_code=3)
    live = read_state(r)
    check_management(d, live)
    ops = diff(live, d.state)
    if not ops:
        print("switch: in sync")
        return 0
    for op in ops:
        print(f"  {op.why}")
    canaries = canary_ips(r, d, changed_ports(live, d.state))
    answering = r.responders(canaries)
    print(f"canaries answering ARP: {', '.join(sorted(answering, key=ipaddress.IPv4Address)) or 'none'}")
    r.arm_deadman(diff(d.state, live), args.deadman)
    print(f"dead-man armed: the router reverts these writes in {args.deadman} min unless this run confirms")
    results = r.apply(ops)
    if args.simulate_session_loss:
        print("simulated session loss: leaving the dead-man armed")
        return 1
    problems = []
    for line in results:
        if line.startswith("FAIL"):
            _, i, *msg = line.split(" ", 2)
            problems.append(f"write failed: {ops[int(i)].why}: {' '.join(msg)}")
    if len(results) < len(ops) and not problems:
        problems.append(f"only {len(results)} of {len(ops)} writes reported (ssh?)")
    if not problems:
        left = diff(read_state(r), d.state)
        if left:
            problems.append("the switch does not match the file: " + "; ".join(op.why for op in left))
        lost = answering - r.responders(sorted(answering))
        if lost:
            problems.append(f"no longer answering ARP: {', '.join(sorted(lost))}")
    if problems:
        print("verify FAILED:\n  " + "\n  ".join(problems) + "\nreverting now")
        revert_to(r, live)
        r.disarm_deadman()
        raise SwctlError("apply reverted; the switch is as it was")
    r.disarm_deadman()
    print(f"switch: {len(ops)} writes applied and verified, dead-man disarmed. "
          "Not saved: `swctl save` once it has settled (a reboot returns to the saved config).")
    return 0
```

```python
"""Telnet client for the TEG-30284 CLI, run on the router. Whitelisted commands
only; `logout` always, because a session closed without it leaks one of the
switch's ~4 CLI slots until it times out."""
import re
import socket
import sys
import time

HOST, PORT = "192.168.10.200", 23
ALLOWED = {"save", "show switch", "show ipif"}
PAGER = re.compile(r"CTRL\+C.*?Next Entry\s+a All\s*", re.S)
ANSI = re.compile(r"\x1b\[[0-9;]*[A-Za-z]")
PROMPT = re.compile(rb"[\w\-.]*[#>]\s*$")


def allowed(cmd: str) -> bool:
    return cmd in ALLOWED


def clean(text: str) -> str:
    return PAGER.sub("", ANSI.sub("", text)).replace("\r", "").strip()


def session(host, password, commands):
    s = socket.create_connection((host, PORT), timeout=10)
    s.settimeout(0.3)

    def read(wait, until=None):
        buf, end = b"", time.time() + wait
        while time.time() < end:
            try:
                d = s.recv(4096)
            except socket.timeout:
                continue
            if not d:
                break
            out, i = b"", 0
            while i < len(d):                    # refuse all telnet options
                if d[i] == 255 and i + 2 < len(d) and d[i + 1] in (251, 252, 253, 254):
                    s.sendall(bytes([255, 254 if d[i + 1] in (251, 252) else 252, d[i + 2]]))
                    i += 3
                else:
                    out += d[i:i + 1]
                    i += 1
            buf += out
            if b"Next Page" in buf[-120:]:
                s.sendall(b"a")
            if re.search(rb"\(y/n\)|\[y/n\]", buf[-80:], re.I):
                s.sendall(b"y\r\n")
            if until is not None and until.search(buf):
                break
        return buf.decode(errors="replace")

    banner = read(5, re.compile(rb"(sername|ogin)\s*:\s*$"))
    if "Exceeding Max Cli Sessions" in banner:
        s.close()
        raise SystemExit("switch CLI: every session slot is taken (leaked sessions) - wait for them to time out")
    s.sendall(b"admin\r\n")
    read(4, re.compile(rb"assword\s*:\s*$"))
    s.sendall(password.encode() + b"\r\n")
    after = read(5, PROMPT)
    if not PROMPT.search(after.encode()) or re.search(r"(?i)fail|denied|invalid|incorrect", after):
        s.close()
        raise SystemExit("switch CLI: login failed")
    try:
        for c in commands:
            if not allowed(c):
                print(f"refused (not whitelisted): {c!r}")
                continue
            s.sendall(c.encode() + b"\r\n")
            print(f"== {c}\n{clean(read(30 if c == 'save' else 8, PROMPT))}")
    finally:
        s.sendall(b"logout\r\n")
        time.sleep(1.0)
        s.close()


if __name__ == "__main__":
    session(globals().get("HOST_OVERRIDE", HOST), PASSWORD, COMMANDS)  # noqa: F821 (prepended by Router.cli)
```
