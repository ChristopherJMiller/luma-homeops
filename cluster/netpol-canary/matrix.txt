# NetworkPolicy canary target matrix (design §6.4). Read by probe.sh; selftest and
# scripts/test_netpol_manifests.py pin its shape.
#
# Columns, whitespace-separated:  expect scope host port backend note...
#   expect   dns      the name resolves (port is unused); judged "open" in both modes
#            open     a TCP connect must succeed
#            dropped  the packet must be dropped: enforced = timeout; a refusal (RST)
#                     means it got through, so it FAILs. baseline = open or refused,
#                     which proves the target is alive before any policy exists.
#   scope    all      the canary and the forgejo-runner (probe.sh SCOPE=runner)
#            canary   canary only (the echo server lives in netpol-canary)
#   backend  "-", or ns/service whose EndpointSlice IPs are the post-DNAT destination
#            that deny logs show (design §3.4 item 1).
# Variables: $HOST_IP is the probe pod's node; $PEER_IP is the next node after it in
# probe.sh's NODE_IPS (top, middle, bottom, then top again), so each probe dials another
# node and every node gets dialled; $WAN_IP is git.realliance.net's A record, resolved on
# every run. A selected row with the variable unset is an error.
# BMC IPs are copied from cluster/ipmi-exporter/scrapeconfig.yaml; a test keeps them in step.
